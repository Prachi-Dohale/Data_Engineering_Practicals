# Practical 10 – End-to-End Data Engineering Mini Project

## Aim

Design and implement an end-to-end data engineering solution including
data ingestion, cleaning, transformation, storage, data warehouse design,
and reporting.

## Project

Supply Chain Data Engineering and Analytics

## Pipeline

Raw Dataset
→ Data Ingestion
→ Data Cleaning
→ Transformation
→ Data Warehouse
→ SQL Analysis
→ Power BI Reporting

## Technologies Used

- Python
- Pandas
- SQL
- SQLite / SQL Server
- Power BI
- GitHub

## Project Structure

- `data/` – Dataset and input data
- `scripts/` – Python ETL scripts
- `sql/` – SQL queries and database scripts
- `database/` – Database/warehouse files
- `powerbi_data/` – Data prepared for Power BI
- `reports/` – Reports and dashboard screenshots
- `docs/` – Project documentation
